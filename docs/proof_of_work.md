## Verification Commands

Run the following commands from the repository root.

```powershell
python -m src.model_evaluation
python -m src.threat_detection
python -m src.visualization
python -m src.simulation --samples-per-class 50
python -m pytest -v
```

Check Python syntax:

```powershell
python -m compileall -q main.py src app tests
```

Run these commands using the documented virtual environment and the correctly downloaded dataset.

## Output Integrity

- Use actual generated metrics and model outputs.
- Do not invent accuracy, precision, recall, F1 score, or alert counts.
- Label the small balanced simulation as a demonstration sample.
- Do not describe a predicted alert as a confirmed security incident.
- Do not include raw datasets or trained model artifacts without reviewing repository size and applicable terms.
- Avoid publishing secrets, access tokens, or private information in screenshots.
